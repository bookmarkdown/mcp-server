## Concepts

* `m-page.svg`: solid teal bookmark, rounded lower tips, wide negative-space M, two quiet curved cuts.
* `m-loop.svg`: narrow brown outlined bookmark, soft handwritten M, sparse curved underline.
* `m-leaves.svg`: wide muted-violet bookmark, split two-page M, restrained corner arcs.

Each includes a `-mono.svg` counterpart using `currentColor` when embedded inline. `preview.png` shows the three designs and reduced sizes. All SVGs use self-contained vector geometry without font or raster dependencies, and all were rendered successfully. Each concept redesigns the M, bookmark shape, background, and palette; none includes B or D in the icon. The server UI is not modified.
