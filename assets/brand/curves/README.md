## Direction

Inspired by the reference's curved parallel-line rhythm, this original BMD monogram uses rounded ribbon forms and one color, without a crest, rays, diamonds, or stepped frame. The central M is taller than B and D. The rounded lowercase wordmark echoes the first design direction.

## Assets

* `bmd-symbol.svg`, `bmd-symbol-dark.svg`: standalone marks.
* `bookmarkdown-logo.svg`, `bookmarkdown-logo-dark.svg`: horizontal signatures.
* `-mono.svg` variants use `currentColor` when embedded inline.
* `preview.png`: light/dark and size previews.

The SVGs use vector paths and a self-contained mask that produces genuinely transparent gaps between the parallel lines. No fonts, raster images, scripts, or external resources are needed. Use the symbol at 96 px or wider to preserve the double-line detail. The assets are supplied independently and do not change the server interface.
