## Direction

An open BMD monogram replaces the bookmark badge. The central M rises above B and D, and its two green tones suggest a folded page. The accompanying custom uppercase wordmark uses open geometric strokes. Forest `#16352E`, mint `#2BC9A2`, and folded mint `#17A889` define the palette.

## Assets

* `bmd-symbol.svg`, `bmd-symbol-dark.svg`: standalone marks for light/dark backgrounds.
* `bmd-symbol-mono.svg`: single-color mark using `currentColor` when embedded inline.
* `bookmarkdown-logo.svg`, `bookmarkdown-logo-dark.svg`: horizontal signatures.
* `bookmarkdown-logo-mono.svg`: single-color horizontal signature.
* `preview.png`: presentation sheet with large and small applications.

All SVGs have transparent backgrounds and use vector paths, including the wordmark; no fonts, scripts, embedded images, or external resources are required. Recommended minimum monogram width is 50 px. Keep at least one letter-stem width of clear space. This is an independent design option and is not applied to the server interface.
