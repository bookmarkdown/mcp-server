## Design

The BMD crest uses a taller and heavier central M, stepped symmetry, radial lines, angular letterforms, and diamond details. The custom uppercase wordmark uses narrow geometric strokes. The dark application pairs jade `#10241F` with champagne `#D7B877`; light applications use deep green lines and bronze `#997032` for the M.

## Files

* `bookmarkdown-logo.svg`, `bookmarkdown-logo-dark.svg`: horizontal signatures for light/dark backgrounds.
* `bmd-emblem.svg`, `bmd-emblem-dark.svg`: detailed square crests.
* `bmd-monogram.svg`, `bmd-monogram-dark.svg`: compact marks with the ornament removed for smaller applications.
* Corresponding `-mono.svg` versions use `currentColor` when embedded inline.
* `preview.png`: light/dark signatures, crest, compact mark, and palette.

All SVGs use vector paths without font, script, or external-resource dependencies and have transparent backgrounds. Use the detailed crest at 120 px or larger; below that, use the compact mark, preferably at least 60 px wide. This option is supplied independently and does not modify the server UI.
