## Background options

The M letterform, foreground clear space, bookmark silhouette, and palette match the preceding M bookmark design. Only the background pattern changes.

* `flow`: two groups of gently flowing parallel curves.
* `orbit`: offset concentric arcs at opposite corners.
* `arch`: symmetrical nested rounded arches.

Each option includes light and dark SVG files. All use a transparent exterior and self-contained vector geometry. `preview.png` compares the six marks. The server UI remains unchanged.
